# feeder

A local-first RSS/Atom collector and personal digest CLI. Feed excerpts by default; opt-in summaries with Ollama or an OpenAI-compatible API. Markdown for reading, JSON for automation.

MIT licensed. Go + SQLite, single binary for Linux and macOS.

**Status:** specification complete; implementation begins with M0. No working CLI release yet.
